Personalizarás la habilidad existente `quality-checks` y la usarás para ejecutar las comprobaciones del proyecto.

1. Abre la definición de la habilidad.
2. Revisa sus instrucciones y scripts.
3. Cambia el formato del informe según el ejercicio.
4. Ejecuta la habilidad y comprueba sus resultados.
