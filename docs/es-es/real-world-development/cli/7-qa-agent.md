Crearás un agente especializado en aseguramiento de calidad para revisar requisitos, cobertura y evidencia de verificación.

1. Crea el perfil del agente de QA.
2. Define sus responsabilidades y criterios de revisión.
3. Selecciona el agente para la sesión.
4. Pídele que revise la implementación y las pruebas.
5. Atiende los resultados que requieran cambios.
