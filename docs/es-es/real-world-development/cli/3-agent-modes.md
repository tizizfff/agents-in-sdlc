Utilizarás los modos Plan, Autopilot e Interactive para implementar la función de filtrado.

1. Planifica la solución a partir de la incidencia.
2. Revisa el plan y los archivos afectados.
3. Pide a Copilot que implemente el cambio en el modo Autopilot.
4. Cambia al modo Interactive para revisar y corregir el resultado.
5. Ejecuta las pruebas y confirma el cambio.
