Antes de comenzar el taller de Visual Studio Code, prepara tu repositorio y el entorno de desarrollo.

## Crea el repositorio

1. Abre la [plantilla de Tailspin Toys][tailspin-template].
2. Selecciona **Use this template** y después **Create a new repository**.
3. Crea el repositorio en una organización o con tu cuenta personal, según tengas acceso a GitHub Copilot.

## Crea un Codespace

1. Abre el nuevo repositorio.
2. Selecciona **Code** y después la pestaña **Codespaces**.
3. Selecciona **+** para crear un Codespace.

> [!NOTE]
> El taller puede ejecutarse en un Codespace o en un contenedor de desarrollo local. Ambos proporcionan las herramientas y las dependencias necesarias.
