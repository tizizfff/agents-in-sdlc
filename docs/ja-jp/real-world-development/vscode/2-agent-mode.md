Copilot Chat のエージェントモードを使用して、Issue の要件を確認し、関連ファイルを調査し、変更案を実装します。

変更を依頼する前に、対象範囲と検証手順を明確にしてください。エージェントが提案した差分、コマンド、テスト結果を確認し、必要な修正をフィードバックします。
