この演習では、GitHub Issue を Copilot cloud agent に割り当て、バックグラウンドで機能や修正を実装します。

## Issue を割り当てる

1. 対象リポジトリで Issue を開きます。
2. Issue に Copilot cloud agent を割り当てます。
3. エージェントダッシュボードでセッションの開始、調査、変更、プルリクエスト作成を確認します。

> [!NOTE]
> エージェントが作業を開始すると、セッション中に進捗を確認できます。変更を承認する前に、生成された差分とテスト結果をレビューしてください。
