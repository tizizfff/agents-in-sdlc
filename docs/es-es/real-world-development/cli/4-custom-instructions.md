Explorarás y actualizarás las instrucciones del repositorio y las aplicarás al trabajo de filtrado.

1. Revisa `.github/copilot-instructions.md`.
2. Identifica las convenciones de código y pruebas.
3. Añade o mejora la directriz necesaria.
4. Solicita a Copilot que vuelva a aplicar las instrucciones al filtrado.
5. Revisa el diff y verifica el resultado.
