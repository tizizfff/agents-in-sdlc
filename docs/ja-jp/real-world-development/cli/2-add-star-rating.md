この演習では、既存の `starRating` をゲームカードに表示し、評価されていない状態を明示的に追加します。

1. 対象 Issue または要件を確認します。
2. Copilot CLI にアプリの構造、既存コンポーネント、テストを調査させます。
3. 星評価と未評価状態の実装を依頼します。
4. 差分を確認し、自動テストとブラウザ表示を確認します。
5. レビュー可能な変更をプルリクエストとして作成します。
