Revisarás el cambio completo de filtrado y utilizarás Agent Merge para abrir y combinar la solicitud de incorporación de cambios.

1. Revisa todos los cambios y las comprobaciones.
2. Crea la solicitud de incorporación de cambios desde la rama actual.
3. Confirma que el título y la descripción describen el trabajo.
4. Espera a que finalicen las comprobaciones obligatorias.
5. Utiliza Agent Merge solo después de la revisión.
