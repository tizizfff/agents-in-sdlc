この演習では、リポジトリにカスタムインストラクションを追加して、cloud agent がワークショップのコーディング規約、テスト、レビュー要件を理解できるようにします。

## この演習で行うこと

- cloud agent の作業範囲と対象に関連するプロジェクトガイドラインを確認します。
- `.github/copilot-instructions.md` または適切なパススコープのインストラクションファイルを確認・更新します。
- 変更をコミットし、agent の Issue 処理時にインストラクションが適用されることを確認します。

インストラクションには、技術スタック、テストコマンド、スタイル規約、変更時に避けるべき事項を具体的に記述してください。
