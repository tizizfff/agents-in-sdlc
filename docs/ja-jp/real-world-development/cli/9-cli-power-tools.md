## その他の CLI 機能

- `/review` - コードレビューエージェントに変更を分析させます。
- `/rubber-duck` - 問題を整理し、別の視点を得ます。
- `/fleet` - 独立したサブタスクを並行実行します。
- `/worktree` - 別の作業ツリーを分離します。
- `/delegate` - 作業を Copilot cloud agent に委任します。

タスクの内容に合った機能を選択し、モデルと実行モードの影響を確認してください。
