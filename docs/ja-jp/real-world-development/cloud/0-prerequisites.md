この演習では、GitHub Copilot cloud agent ワークショップを実行するためのリポジトリ、権限、開発環境を確認します。

## 前提条件

- GitHub アカウント
- cloud agent を利用できる Copilot プラン
- このワークショップ用のリポジトリと Codespace

ワークショップの手順に従って環境を準備し、次の演習に進んでください。
