この演習では、cloud agent が作成したプルリクエストをレビューし、必要な修正をフィードバックとして与えます。

## レビュー手順

1. プルリクエストの変更、テスト、説明を確認します。
2. 要件との差分や品質上の懸念を特定します。
3. 具体的で再現可能なフィードバックを残します。
4. agent に修正を依頼し、更新された差分を再度確認します。
5. 必要なチェックと承認が完了した後でマージするか、次の作業を選択します。
