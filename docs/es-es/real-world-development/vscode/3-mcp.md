Conectarás el servidor MCP de Playwright a Copilot para observar el comportamiento del sitio desde un navegador.

1. Configura el servidor MCP siguiendo la documentación del entorno de VS Code.
2. Inicia el servidor y confirma que aparece en Copilot Chat.
3. Pide a Copilot que abra la aplicación y pruebe el filtrado.
4. Revisa las observaciones del navegador y solicita cambios si el comportamiento no coincide con los requisitos.
5. Ejecuta las comprobaciones automatizadas disponibles.
