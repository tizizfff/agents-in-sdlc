Plan モードでフィルタリングの実装方法を検討し、Interactive モードで変更を段階的に確認しながら進め、スコープが明確な場合は Autopilot モードで実装を進めます。

各モードでは、タスクの複雑さと必要な確認の度合いに応じて、エージェントとの対話レベルを選択してください。変更後は、コード、テスト、ブラウザ動作を確認します。
