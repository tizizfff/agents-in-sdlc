Configurarás el servidor MCP de Playwright y lo utilizarás para observar el filtrado en un navegador.

1. Añade la configuración del servidor MCP.
2. Inicia el servidor y habilita la integración en CLI.
3. Pide a Copilot que abra la aplicación y pruebe el filtrado.
4. Revisa el comportamiento observado y solicita correcciones si es necesario.
