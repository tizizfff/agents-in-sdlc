En este ejercicio utilizarás el modo agente de Copilot Chat para implementar una función de filtrado en la aplicación Tailspin Toys.

1. Abre Copilot Chat en VS Code y selecciona el modo agente.
2. Describe la función de filtrado y referencia la incidencia correspondiente del backlog.
3. Revisa el plan propuesto antes de permitir modificaciones.
4. Inspecciona cada cambio en el editor y ejecuta las pruebas indicadas.
5. Comprueba la función en el navegador integrado o en la aplicación ejecutándose localmente.

> [!IMPORTANT]
> Revisa siempre los cambios y valida los resultados. El modo agente puede modificar varios archivos de forma independiente.
