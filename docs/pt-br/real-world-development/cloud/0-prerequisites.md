Antes de iniciar os exercícios do agente de nuvem do Copilot, prepare o ambiente. Você criará sua própria cópia do repositório Tailspin Toys e iniciará um [codespace][codespaces] para editar arquivos de instruções e revisar o trabalho do agente.

## Configurar o repositório do laboratório

Crie uma instância a partir do [modelo][template-repository].

1. Abra o [modelo Tailspin Toys][tailspin-template].
2. Selecione **Use this template** e depois **Create a new repository**.

   ![Botão Use this template](../../../_images/ex0-use-template.png)

3. Se estiver participando de um evento conduzido pelo GitHub ou pela Microsoft, siga as orientações dos facilitadores. Caso contrário, crie o repositório em uma organização em que tenha acesso ao GitHub Copilot.

   ![Configurações do repositório criado a partir do modelo](../../../_images/ex0-repository-settings.png)

4. Anote o caminho criado (**organization-or-user-name/repository-name**), pois você precisará dele nos exercícios.

## Criar um codespace

O [GitHub Codespaces][codespaces] oferece um ambiente de desenvolvimento na nuvem com IDE, linguagens, extensões e ferramentas.

1. Abra o repositório criado.
2. Selecione o botão verde **Code**.
3. Selecione **Codespaces** e o botão **+** para criar um Codespace.

   ![Criar um codespace](../../../_images/ex0-create-codespace.png)

> [!CAUTION]
> Você retornará a este codespace em uma atividade futura. Por enquanto, deixe-o aberto em uma guia do navegador.

> [!NOTE]
> Este workshop pode ser executado em um codespace ou em um [dev container][dev-containers] local. Os dois ambientes incluem os pré-requisitos necessários.

## Resumo

Você criou uma cópia do repositório e iniciou a criação do codespace.
