MCP サーバーを構成し、Copilot が必要なツールやデータソースにアクセスできるようにします。

- サーバー構成を確認します。
- 接続と利用可能なツールをテストします。
- エージェントに対して、MCP を使用した具体的なタスクを依頼します。
- サーバーから返された結果を確認し、ソースの真偽と変更内容を検証します。
