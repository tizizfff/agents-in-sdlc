この演習では、Playwright MCP サーバーを Copilot CLI に追加し、実ブラウザでアプリケーションを操作します。

1. MCP サーバーの構成を確認します。
2. フィルタリング操作を実行できることを確認します。
3. 結果、スクリーンショット、ブラウザの観察事項を記録します。
4. 要件とのずれや回帰を特定し、必要な修正を依頼します。
