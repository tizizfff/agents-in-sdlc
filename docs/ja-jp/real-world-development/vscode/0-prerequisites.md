このワークショップを始める前に、GitHub アカウント、Copilot プラン、リポジトリ、Visual Studio Code または Codespace を準備します。

- リポジトリへのアクセス権があること
- GitHub Copilot と拡張機能が有効なこと
- MCP サーバーやカスタムエージェントを使用するための権限があること
