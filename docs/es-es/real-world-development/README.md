Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante escenarios realistas, una aplicación completa y una acumulación de trabajo compartida. Trabajarás de forma iterativa para planificar cambios, crear código, probar comportamientos, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres una persona desarrolladora nueva en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog de tu equipo ya está registrado en GitHub Issues, listo para que elijas tareas. Incluye trabajo de características, como el filtrado y la paginación, junto a mejoras de calidad, como la accesibilidad y los estándares de código.

## Elige tu entorno

GitHub Copilot está disponible allí donde trabajes. Elige el entorno que se ajuste a la forma en que prefieras desarrollar. Cada taller comienza con su propia configuración y utiliza el mismo escenario de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Utiliza el asistente agéntico en tu terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, MCP de Playwright, Agent Merge y comandos de barra útiles.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia los modos de sesión, colabora en lienzos y gestiona incidencias y solicitudes de incorporación de cambios de GitHub en la aplicación de escritorio.

### [Agente de GitHub Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asincrónico, guía su trabajo, supervisa el progreso y revisa las solicitudes de incorporación de cambios que abra.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
