この演習では、特定の役割やレビュー観点を持つカスタムエージェントを確認します。カスタムエージェントは、対象タスクに応じた専門的な指示をエージェントに与えます。

1. 利用可能なカスタムエージェントを確認します。
2. タスクに適したエージェントを選択します。
3. エージェントの結果が要件とプロジェクト規約に合っているか確認します。
