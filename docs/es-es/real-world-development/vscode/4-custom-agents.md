Los agentes personalizados permiten crear asistentes especializados a partir de archivos Markdown en `.github/agents`.

1. Revisa el archivo del agente de accesibilidad.
2. Comprueba sus campos `name` y `description` y sus instrucciones.
3. Selecciona ese agente en Copilot Chat.
4. Pídele que revise la función implementada y corrija problemas de accesibilidad.
5. Revisa el diff y ejecuta las comprobaciones.
